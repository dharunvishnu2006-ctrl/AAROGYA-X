# v1.1 B3 — Honest numbers
# Modules: M6 risk, M15 dashboard
# Twins: CloudShield v1.1 (NumPy/Pandas analytics, p95 threshold),
#        all three projects (theme-aware charts)

## Goal
Every number on the dashboard comes from one tested statistics module,
and every chart is called, tested and readable in light and dark mode.

## Tasks
1. aarogya/m6_risk/cohort_stats.py, vectorised (NumPy/pandas, no row
   loops): for bmi, bp_systolic, bp_diastolic, sugar_fasting ->
   count, mean, median, std, p25, p75, p90, min, max.
2. Group statistics (pandas groupby): by city, by age band
   (<30, 30-44, 45-59, 60+), by risk level.
3. The dashboard computes nothing itself: every metric card and table
   reads from cohort_stats. Remove the old duplicate functions once no
   caller is left (D4).
4. Measure: a plain Python loop vs the vectorised version for mean and
   std, on the 50 sample rows and on 50,000 synthetic rows (fixed
   seed). Print both timings; they go into design.md.
5. Charts (D1): fix plot_city_patient_count (colors= -> color=) and use
   it on the dashboard; remove any inline duplicate chart. Every chart
   function has a caller and a test that checks content (e.g. number of
   bars == number of cities), not just "a figure came back".
6. Theme: transparent figures, mid-tone colours, no hard-coded theme;
   fix the "Distibution" typo.
7. The scatter colours points by risk level with a colour-blind-safe
   palette and a second cue (marker shape or label), not by gender.

## Must not
- Show any number that does not come from cohort_stats.
- Change risk results.

## Allowed tools
numpy, pandas, matplotlib, seaborn, plotly, time.perf_counter, random.

## Verification
- cohort_stats on a 5-row hand-made table matches values worked out
  by hand (a test).
- app.py contains no .mean( / .median( / .std( calls.
- plot_city_patient_count runs; its test checks bars == cities.
- Every page readable with the system theme light AND dark.
- Both timings, both sizes, printed and copied into design.md.

## Out of scope
Interactive filters beyond what exists; any ML.
