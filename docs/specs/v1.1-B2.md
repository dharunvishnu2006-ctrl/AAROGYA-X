# v1.1 B2 — The patient record
# Module: M1 EMR
# Twin: Sentinel v1.1 C4 (OOP agent hierarchy)

## Goal
One clean patient type that cannot be corrupted, one rule for identity,
and one way of storing time.

## Tasks
1. aarogya/m1_emr/models.py: a Person base class (person_id, name).
   Patient(Person) keeps every current field and the A2 validation.
2. Properties with validating setters for age, bmi, bp_systolic,
   bp_diastolic, sugar_fasting, using the ranges in clinical_config.
   Setting an impossible value after construction raises ValueError.
3. Identity: two Patients are equal if and only if patient_id is equal.
   __hash__ matches __eq__. __str__ shows id + name initial only
   (e.g. "P007 · Pushti J."), never vitals.
   __lt__ orders by risk level (High > Medium > Low), then patient_id.
4. Risk scoring as a strategy: a RiskScorer interface and one class,
   ThresholdRiskScorer, holding today's rules unchanged.
   score_patient_risk() keeps working and delegates to it.
5. Doctor is used nowhere: remove it (clinicians return with M12).
   Remove every unused import (D4).
6. patient_id must match ^P[0-9]{3,}$. A malformed id is rejected at
   the boundary with a message that states the format.
7. Time: every stored timestamp is UTC ISO-8601 (+00:00). The dashboard
   shows Indian time (Asia/Kolkata). Any date text in an upload is
   parsed with an explicit format, never guessed.

## Must not
- Change the risk band of any sample patient.
- Merge two patients, or treat two ids as one.

## Allowed tools
classes, properties, abc or typing.Protocol, re, datetime, zoneinfo.

## Verification
- Patient P007 == another Patient P007 with a different name -> True.
- Two patients, same name/age/city, ids P007 and P031 -> not equal.
- p.age = -5 -> ValueError.
- A test compares the risk band of all 50 sample patients before and
  after -> identical.
- Ids "7", "p007", "PX01" -> rejected with the format message.
- A stored timestamp ends with +00:00; the dashboard shows it in IST.

## Out of scope
Date of birth instead of age (needs a schema change — v2).
Merging duplicate records (v2).
