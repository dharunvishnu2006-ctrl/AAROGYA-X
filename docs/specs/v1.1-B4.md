# v1.1 B4 — Occupancy and the read API
# Modules: M2 HIS (begins), platform
# Twins: CloudShield v1.1 (Flask alert API),
#        Sentinel v1.1 C9 (REST clients for both flagships)

## Goal
Replace the meaningless occupancy figure with one based on real stays,
and expose the dashboard's data through a small read-only API.

## Tasks
1. aarogya/m2_his/: one Hospital class (id, name, city, total_beds) and
   a "stays" table in the clinical store: stay_id, patient_id (FK),
   hospital_id, ward, bed, admitted_at (UTC), discharged_at (UTC or NULL).
2. Stay rules: a patient cannot have two open stays; a bed holds at most
   one open stay; discharge must be after admission; a patient never
   admitted cannot be discharged. Violations raise a clear error.
3. Occupancy per hospital = open stays / total_beds, shown per hospital.
   Above 100% is shown and flagged - never clamped.
4. data/generate_data.py also generates synthetic hospitals and stays
   for the sample patients (fixed seed). Loading runs extract ->
   validate -> load, logging the counts (no patient data in logs).
5. aarogya/platform/api.py (Flask), read-only, bound to 127.0.0.1:
   GET /health               -> the B1 health result
   GET /cohort/stats         -> cohort_stats summary
   GET /patients/<id>        -> id, age band, city, vitals, risk
                                (no name)
   GET /hospitals/occupancy  -> per hospital
   Routes are thin: parse, validate, call one function, return JSON.
   Bad id -> 400 with the format message. Unknown id -> 404.
   Never a 500 from deep inside.
6. Known limit "No authentication yet - API is localhost only":
   I add this to design.md myself. Do not edit design.md.

## Must not
- Compute occupancy from city.
- Return a patient name from the API.
- Use SQL joins (Layer 3) - keep queries single-table.

## Allowed tools
sqlite3, flask, json, datetime, random (seeded), pandas.

## Verification
- Patients in Chennai but no open Chennai stays -> Chennai 0%, not
  "patients / beds".
- Admit the same patient twice -> refused. Discharge a never-admitted
  patient -> refused. Discharge before admission -> refused.
- GET /patients/PX01 -> 400 with format message; /patients/P999 -> 404;
  /health -> reflects the store's real state.
- Flask test-client tests for every route; no network needed.

## Out of scope
Transfers between wards, waiting lists, login (later versions).
